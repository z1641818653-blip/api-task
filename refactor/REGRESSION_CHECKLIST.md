# Workflow 回归测试清单

## 基线保护

- [ ] 稳定页面仍可打开。
- [ ] 重构页面首次打开可正常初始化。
- [ ] 刷新页面后流程和当前节点不会丢失。
- [ ] 主节点缺失的数据能够自动恢复。

## 节点操作

- [ ] 主节点不可删除、不可拖动。
- [ ] 主节点可以锁定编辑和解除锁定。
- [ ] 主节点和子节点均可复制。
- [ ] 添加子节点正常。
- [ ] 仅删除当前节点时，直接子节点提升到上一级。
- [ ] 删除分支只删除目标节点及其后代。
- [ ] 跨层拖拽不会形成循环或丢失节点。
- [ ] 锁定节点不会被误删或误拖动。

## 属性与状态

- [ ] 主节点只显示手动输入，不显示继承来源。
- [ ] 子节点可在手动输入和继承上级之间切换。
- [ ] 输入为空显示红色。
- [ ] 输入有效但 Prompt 为空显示蓝色。
- [ ] 待执行显示灰色。
- [ ] 执行中或结果过期显示黄色。
- [ ] 执行成功且结果有效显示绿色。
- [ ] 自定义分类色签与运行状态颜色可以同时显示。

## 执行

- [ ] 单节点执行会检查全部上级是否完成。
- [ ] 依赖链执行按上级到当前节点运行。
- [ ] 依赖链复用已完成且有效的上级结果。
- [ ] 整树执行按深度优先顺序运行所有可执行节点。
- [ ] 多分支共享上级只执行一次。
- [ ] 红色或蓝色问题出现时允许返回完善或强制执行。
- [ ] 停止按钮能中断队列并标记未完成节点。
- [ ] DeepSeek 流式输出、HTTP 错误和中断错误显示正常。

## 保存与交换

- [ ] 保存和加载保留完整树结构。
- [ ] 导入同名流程自动增加“（1）”。
- [ ] 导入旧格式流程能够规范化字段。
- [ ] 导出后重新导入保持结构一致。
- [ ] 撤销和重做可双向切换，最多保留 5 次。
- [ ] 撤销后产生新修改会清空重做栈。
